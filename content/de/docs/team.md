# Team

$mol wird offen von **[hyoo-ru](https://github.com/hyoo-ru)** entwickelt — der Community rund um seinen Autor, Dmitry Karlovsky ([nin-jin](https://github.com/nin-jin)). Die Entwicklung findet in einem einzigen Monorepo statt, [mam_mol](https://github.com/hyoo-ru/mam_mol), wo das Framework, seine Komponenten und das Werkzeug alle zusammen leben.

Das Ökosystem ist Gemeinschaftsarbeit: das Kern-Framework, die CRDT-Bibliothek [$hyoo_crowd](https://github.com/hyoo-ru/crowd.hyoo.ru), [Giper Baza](https://github.com/giper-dev/baza) und Dutzende veröffentlichter Komponenten stammen alle von Mitwirkenden, die im selben Workspace arbeiten.

## Mitwirken

- Das gesamte Ökosystem ist MIT-lizenziert und offen für Pull Requests.
- Jedes Modul lebt im Monorepo [mam_mol](https://github.com/hyoo-ru/mam_mol) — forken, einen Ordner hinzufügen, einen PR öffnen.
- Diskutieren Sie Ideen und teilen Sie, was Sie bauen, in der [DEV-Community](https://dev.to/t/mol).

Diese Dokumentationsseite wird separat unter [b-on-g/smalljs](https://github.com/b-on-g/smalljs) gepflegt; jede Seite hat einen *Auf GitHub bearbeiten*-Link, falls Ihnen etwas zum Verbessern auffällt.

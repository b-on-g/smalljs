# $mol_pick

`$mol_pop` を継承。[GitHub でソースを見る](https://github.com/hyoo-ru/mam_mol/tree/master/pick)

このリファレンスはコンポーネントの型付き `.view.tree` インターフェイスから生成されています。

## プロパティ

| プロパティ | アクセス | 型 |
|---|---|---|
| `trigger_enabled` | 読み取り | `boolean` |
| `trigger_content` | 読み取り | `readonly($mol_view_content)[]` |
| `hint` | 読み取り | `string` |
| `Trigger` | 読み取り | `$mol_check` |
| `event` | 読み取り | `({` |
| `Anchor` | 読み取り | `as 'Trigger'` |

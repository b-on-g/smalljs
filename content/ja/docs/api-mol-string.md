# $mol_string

`$mol_view` を継承。[GitHub でソースを見る](https://github.com/hyoo-ru/mam_mol/tree/master/string)

このリファレンスはコンポーネントの型付き `.view.tree` インターフェイスから生成されています。

## プロパティ

| プロパティ | アクセス | 型 |
|---|---|---|
| `disabled` | 読み取り | `boolean` |
| `value` | 読み取り / 書き込み | `string` |
| `value_changed` | 読み取り / 書き込み | `as 'value'` |
| `hint` | 読み取り | `string` |
| `hint_visible` | 読み取り | `as 'hint'` |
| `spellcheck` | 読み取り | `boolean` |
| `autocomplete_native` | 読み取り | `string` |
| `selection_end` | 読み取り | `number` |
| `selection_start` | 読み取り | `number` |
| `keyboard` | 読み取り | `string` |
| `enter` | 読み取り | `string` |
| `length_max` | 読み取り | `number` |
| `type` | 読み取り / 書き込み | `string` |
| `submit_with_ctrl` | 読み取り | `boolean` |
| `Submit` | 読み取り | `$mol_hotkey` |
| `dom_name` | 読み取り | `string` |
| `enabled` | 読み取り | `boolean` |
| `minimal_height` | 読み取り | `number` |
| `autocomplete` | 読み取り | `boolean` |
| `auto` | 読み取り | `readonly(any)[]` |
| `field` | 読み取り | `({` |
| `attr` | 読み取り | `({` |
| `event` | 読み取り | `({` |
| `plugins` | 読み取り | `readonly(any)[]` |

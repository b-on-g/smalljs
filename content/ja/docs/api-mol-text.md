# $mol_text

`$mol_list` を継承。[GitHub でソースを見る](https://github.com/hyoo-ru/mam_mol/tree/master/text/text)

このリファレンスはコンポーネントの型付き `.view.tree` インターフェイスから生成されています。

## プロパティ

| プロパティ | アクセス | 型 |
|---|---|---|
| `highlight` | 読み取り | `string` |
| `code_sidebar_showed` | 読み取り | `boolean` |
| `pre_sidebar_showed` | 読み取り | `as 'code_sidebar_showed'` |
| `uri_base` | 読み取り | `string` |
| `text` | 読み取り | `string` |
| `param` | 読み取り | `string` |
| `flow_tokens` | 読み取り | `readonly(any)[]` |
| `auto` | 読み取り | `readonly(any)[]` |

# $mol_check

`$mol_button_minor` を継承。[GitHub でソースを見る](https://github.com/hyoo-ru/mam_mol/tree/master/check)

このリファレンスはコンポーネントの型付き `.view.tree` インターフェイスから生成されています。

## プロパティ

| プロパティ | アクセス | 型 |
|---|---|---|
| `checked` | 読み取り / 書き込み | `boolean` |
| `aria_checked` | 読み取り | `string` |
| `aria_role` | 読み取り | `string` |
| `title` | 読み取り | `string` |
| `Title` | 読み取り | `$mol_view` |
| `label` | 読み取り | `readonly(any)[]` |
| `attr` | 読み取り | `({` |
| `sub` | 読み取り | `readonly($mol_view_content)[]` |

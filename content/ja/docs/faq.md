# よくある質問

## smalljs とは？

smalljs は **$mol** のドキュメントサイトです——型付きビュー、自動リアクティビティ、仮想 DOM なしのリアクティブ UI フレームワークです。フレームワーク自体は hyoo-ru コミュニティによってオープンに開発されています。このサイトはガイド、インタラクティブなコース、ライブのプレイグラウンド、API リファレンスを一箇所に集めています。

## $mol は本番運用に耐えますか？

はい。$mol は実際のアプリや社内ツールを動かしています——[ショーケース](#!section=docs/page=showcase)をご覧ください。単一のモノレポ（MAM）から配布され、作者とコミュニティが日々使っています。

## ランタイムはどれくらいの大きさですか？

小さいです。典型的な $mol アプリはおよそ 100 KB のフレームワークコードを配布し、レンダリングは既定で仮想化されます——ビューポート外のコンポーネントは決して作成されません。詳細とベンチマークは[レンダリング](#!section=docs/page=rendering)をご覧ください。

## 新しいテンプレート言語を学ぶ必要がありますか？

`view.tree`、コンポーネントのレイアウトを宣言するためのコンパクトなツリー構文を学びます。意図的に小さく——[ビュー](#!section=docs/page=views)の章が必要なことを一度で網羅します。ロジックは素の TypeScript のまま、スタイルも型付きです。

## React、Vue、Svelte とどう違いますか？

リアクティビティは自動です——`useState` も `useEffect` も手動の購読もありません。あなたは UI が*何であるか*を記述し、$mol が*どのように*、*いつ*更新するかを決めます。[概念の対応表](#!section=docs/page=rosetta)が他のフレームワークの考え方を $mol に対応づけます。

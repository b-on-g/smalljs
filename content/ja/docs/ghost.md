# ゴーストビュー

`$mol_ghost` は**ノードを持たない**ビューです。自分の DOM 要素を作る代わりに、その `Sub()` の要素を借り、そこに自分の属性・スタイル・振る舞いを混ぜ込みます。ソースコードの一行で言えば、*「ビューのロジックを別のコンポーネントの DOM ノードにミックスインする。」*

```tree
$mol_ghost $mol_view
	Sub $mol_view
```

通常の `$mol_view` は自分の要素を描画します。ゴーストは**一つも**描画しません——子の要素を再利用するので、DOM ツリーに余分なものは何も追加されません。

## いつ使うか

既存のコンポーネントに、別の要素で包むこと*なく*振る舞いを付けたいときにゴーストを使います——ドラッグ、ドロップ、スクロール追従、トランジション。フレームワークのいくつかのコンポーネントがこれの上に作られています。

- **`$mol_drag`** / **`$mol_drop`**——ポインターのドラッグ＆ドロップ
- **`$mol_transit`**——出入りのトランジション
- **`$mol_follower`**——スクロールしても要素を別の要素に揃え続ける
- **`$mol_book_page`**——`$mol_book2` ナビゲーション内の 1 ページ

## プラグインとの関係

`$mol_plugin`——あらゆる[プラグイン](#!section=docs/page=plugins)が継承する基底——も同じ理由で要素を持ちません。ホストの要素を追加するのではなく拡張するからです。ゴーストは一般形（子を一つ包み、そのノードを引き継ぐ）で、プラグインは `plugins /` の下に列挙する特化形です。

# $mol_paragraph

`$mol_view` を継承。[GitHub でソースを見る](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

このリファレンスはコンポーネントの型付き `.view.tree` インターフェイスから生成されています。

## プロパティ

| プロパティ | アクセス | 型 |
|---|---|---|
| `line_height` | 読み取り | `number` |
| `letter_width` | 読み取り | `number` |
| `width_limit` | 読み取り | `number` |
| `row_width` | 読み取り | `number` |
| `sub` | 読み取り | `readonly(any)[]` |

# $mol_number

`$mol_view` を継承。[GitHub でソースを見る](https://github.com/hyoo-ru/mam_mol/tree/master/number)

このリファレンスはコンポーネントの型付き `.view.tree` インターフェイスから生成されています。

## プロパティ

| プロパティ | アクセス | 型 |
|---|---|---|
| `precision` | 読み取り | `number` |
| `Hotkey` | 読み取り | `$mol_hotkey` |
| `dec_enabled` | 読み取り | `as 'enabled'` |
| `dec_icon` | 読み取り | `$mol_icon_chevron_left` |
| `Dec` | 読み取り | `$mol_button_minor` |
| `type` | 読み取り | `string` |
| `value_string` | 読み取り / 書き込み | `string` |
| `hint` | 読み取り | `string` |
| `string_enabled` | 読み取り | `as 'enabled'` |
| `String` | 読み取り | `$mol_string` |
| `inc_enabled` | 読み取り | `as 'enabled'` |
| `inc_icon` | 読み取り | `$mol_icon_chevron_right` |
| `Inc` | 読み取り | `$mol_button_minor` |
| `precision_view` | 読み取り | `as 'precision'` |
| `precision_change` | 読み取り | `as 'precision'` |
| `boost` | 読み取り | `number` |
| `value_min` | 読み取り | `number` |
| `value_max` | 読み取り | `number` |
| `value` | 読み取り / 書き込み | `number` |
| `enabled` | 読み取り | `boolean` |
| `plugins` | 読み取り | `readonly(any)[]` |
| `sub` | 読み取り | `readonly(any)[]` |

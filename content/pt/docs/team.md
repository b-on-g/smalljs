# Equipe

$mol é construído abertamente por **[hyoo-ru](https://github.com/hyoo-ru)** — a comunidade em torno de seu autor, Dmitry Karlovsky ([nin-jin](https://github.com/nin-jin)). O desenvolvimento acontece em um único monorepo, [mam_mol](https://github.com/hyoo-ru/mam_mol), onde o framework, seus componentes e as ferramentas vivem todos juntos.

O ecossistema é um esforço coletivo: o framework central, a biblioteca CRDT [$hyoo_crowd](https://github.com/hyoo-ru/crowd.hyoo.ru), o [Giper Baza](https://github.com/giper-dev/baza) e dezenas de componentes publicados vêm todos de contribuidores trabalhando no mesmo workspace.

## Contribuindo

- Todo o ecossistema é licenciado sob MIT e aberto a pull requests.
- Cada módulo vive no monorepo [mam_mol](https://github.com/hyoo-ru/mam_mol) — faça um fork, adicione uma pasta, abra um PR.
- Discuta ideias e compartilhe o que você constrói na [comunidade DEV](https://dev.to/t/mol).

Este site de documentação é mantido separadamente em [b-on-g/smalljs](https://github.com/b-on-g/smalljs); cada página tem um link *Editar no GitHub* se você notar algo a melhorar.

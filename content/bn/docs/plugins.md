# প্লাগইন

**প্লাগইন** হলো এমন একটি কম্পোনেন্ট যার নিজের কোনো DOM এলিমেন্ট নেই। পৃষ্ঠায় রেন্ডার হওয়ার বদলে, এটি যে কম্পোনেন্ট এটিকে হোস্ট করে তার এলিমেন্টে আচরণ যুক্ত করে——অনেকটা একটি ডিরেকটিভের মতো। আপনি view.tree-এ `plugins /`-এর নিচে প্লাগইন তালিকাভুক্ত করেন; সেগুলো ভিউয়ের পাশাপাশি চলে, কিন্তু কখনো তার `sub`-এ দেখা যায় না।

```tree
$my_app $mol_view
	plugins /
		<= Theme $mol_theme_auto
		<= Search_key $mol_hotkey
			key *
				K? <=> open_search?
	sub /
		<= Content $my_content
```

যেহেতু একটি প্লাগইন তার হোস্টের এলিমেন্ট শেয়ার করে, এটি সেই এলিমেন্টে ইভেন্ট লিসেনার, অ্যাট্রিবিউট, বা রিয়্যাক্টিভ সাইড ইফেক্ট যোগ করতে পারে——অতিরিক্ত মার্কআপে না মুড়েই।

## যেসব প্লাগইন আপনি প্রায়ই ব্যবহার করবেন

- **`$mol_hotkey`**——কীবোর্ড শর্টকাট বাঁধে। `key * escape? <=> close?` Escape-এ `close` চালায়; Ctrl/⌘ বাধ্যতামূলক করতে `mod_ctrl true` সেট করুন।
- **`$mol_theme_auto`**——হোস্ট সাবট্রিতে একটি লাইট/ডার্ক থিম প্রয়োগ করে।
- **`$mol_nav`**——কম্পোনেন্টের একটি তালিকার মধ্যে অ্যারো-কী নেভিগেশন (`keys_y`, `current_y`)।
- **`$mol_speech`**——স্পিচ রিকগনিশন ইনপুট।

## একটি লেখা

একটি প্লাগইন `$mol_plugin` কে এক্সটেন্ড করে (যা নিজেই এলিমেন্টহীন) এবং সাধারণত একটি `event` কে একটি হ্যান্ডলারে যুক্ত করে:

```tree
$my_autosave $mol_plugin
	event *
		^
		input? <=> save? null
```

সেই ভিউয়ের `plugins /` তালিকার মাধ্যমে যেকোনো ভিউতে এটি যুক্ত করুন, আর এটি সেই ভিউয়ের এলিমেন্টকে সমৃদ্ধ করে।

# $mol_check

`$mol_button_minor` কে এক্সটেন্ড করে। [GitHub-এ সোর্স দেখুন](https://github.com/hyoo-ru/mam_mol/tree/master/check)

এই রেফারেন্স কম্পোনেন্টের টাইপড `.view.tree` ইন্টারফেস থেকে জেনারেট করা হয়।

| প্রপার্টি | অ্যাক্সেস | টাইপ |

| `aria_checked` | পড়া | `string` |
| `aria_role` | পড়া | `string` |
| `title` | পড়া | `string` |

# $mol_paragraph

`$mol_view` কে এক্সটেন্ড করে। [GitHub-এ সোর্স দেখুন](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

এই রেফারেন্স কম্পোনেন্টের টাইপড `.view.tree` ইন্টারফেস থেকে জেনারেট করা হয়।

| `letter_width` | পড়া | `number` |
| `width_limit` | পড়া | `number` |
| `row_width` | পড়া | `number` |

# $mol_button_minor

`$mol_button_typed` কে এক্সটেন্ড করে। [GitHub-এ সোর্স দেখুন](https://github.com/hyoo-ru/mam_mol/tree/master/button/minor)

এই রেফারেন্স কম্পোনেন্টের টাইপড `.view.tree` ইন্টারফেস থেকে জেনারেট করা হয়।

## প্রপার্টি

$mol_button_minor adds no new bindable properties of its own — see `$mol_button_typed`.

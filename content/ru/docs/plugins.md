# Плагины

**Плагин** — это компонент без собственного DOM-элемента. Вместо того чтобы рендериться в страницу, он присоединяет поведение к элементу компонента, который его хостит — во многом как директива. Плагины перечисляются под `plugins /` в view.tree; они работают рядом со вью, но никогда не появляются в его `sub`.

```tree
$my_app $mol_view
	plugins /
		<= Theme $mol_theme_auto
		<= Search_key $mol_hotkey
			key *
				K? <=> open_search?
	sub /
		<= Content $my_content
```

Поскольку плагин разделяет элемент своего хоста, он может добавлять обработчики событий, атрибуты или реактивные побочные эффекты к этому элементу, не оборачивая его в дополнительную разметку.

## Плагины, которые вы будете использовать часто

- **`$mol_hotkey`** — привязка горячих клавиш. `key * escape? <=> close?` запускает `close` по Escape; поставьте `mod_ctrl true`, чтобы требовать Ctrl/⌘.
- **`$mol_theme_auto`** — применяет светлую/тёмную тему к поддереву хоста.
- **`$mol_nav`** — навигация стрелками по списку компонентов (`keys_y`, `current_y`).
- **`$mol_speech`** — ввод распознаванием речи.

## Написание своего

Плагин наследует `$mol_plugin` (который сам по себе без элемента) и обычно связывает `event` с обработчиком:

```tree
$my_autosave $mol_plugin
	event *
		^
		input? <=> save? null
```

Присоедините его к любому вью через список `plugins /` этого вью, и он дополнит элемент этого вью.

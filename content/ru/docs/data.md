# Загрузка данных

Загрузка удалённых данных в $mol — не особый API: асинхронное значение это просто реактивное свойство, которое возвращает промис. Вью его дожидается, показывает состояние загрузки и перерисовывается, когда оно разрешается.

## Асинхронное свойство

Верните промис из `@ $mol_mem` и читайте его как любое другое значение:

```typescript
namespace $.$$ {
	export class $my_users extends $.$my_users {
		@ $mol_mem
		users() {
			return $mol_fetch.json( 'https://api.example.com/users' ) as {
				id: number
				name: string
			}[]
		}
	}
}
```

`$mol_fetch` приостанавливает фибру, пока не придёт ответ. Пока он в ожидании, любое вью, читающее `users()`, автоматически показывает встроенное состояние загрузки — вы не пишете флаг `isLoading`.

## Рендеринг результата

Свяжите разрешённые данные прямо в список:

```typescript
		@ $mol_mem
		user_names() {
			return this.users().map( user => user.name )
		}
```

Когда промис разрешается, `users()` обновляется, `user_names()` пересчитывается, и список рендерится. Ни колбэков, ни `useEffect`.

## Перезагрузка

Поскольку это просто реактивная ячейка, вы перезапрашиваете данные, инвалидируя её. Завязывайтесь на токен, который можно инкрементить:

```typescript
		@ $mol_mem
		reload_token( next?: number ) {
			return next ?? 0
		}

		@ $mol_mem
		users() {
			this.reload_token() // подписка
			return $mol_fetch.json( 'https://api.example.com/users' ) as unknown[]
		}

		@ $mol_action
		reload() {
			this.reload_token( this.reload_token() + 1 )
		}
```

Вызов `reload()` меняет токен, что инвалидирует `users()`, что перезапрашивает данные.

## Ошибки

Брошенное исключение внутри реактивного свойства всплывает к ближайшему вью, которое рендерит состояние ошибки вместо контента. Чтобы обработать его самому, перехватите и верните запасное значение:

```typescript
		@ $mol_mem
		users_safe() {
			try {
				return this.users()
			} catch( error ) {
				if( error instanceof Promise ) throw error // всё ещё загружается
				return []
			}
		}
```

Переброс `Promise` — это способ дать состоянию загрузки продолжать течь, перехватывая только настоящие ошибки.

# Showcase

Real things built with $mol — from community platforms to developer tools. Each one is a working app, not a demo.

## Applications

- **[vas3k.club](https://vas3k.club)** — a paid community platform. The front end is a $mol single-page app over a Django backend; $mol keeps the many interactive screens (feed, posts, profiles) reactive without a heavy client stack.
- **Bog Music** — a music player that runs both as a Chrome extension and a web app, with background playback and offline caching. $mol drives the UI and the local-first state.
- **Blitz Quiz** — a Kahoot-style live quiz built on $mol and Giper Baza. Rooms sync in real time through the CRDT layer, so there is no game server to run.
- **$mol Styler** — a visual editor for typed `.view.css.ts` styles (a Figma-like surface for $mol components), itself written in $mol.
- **WikiLive** — a local-first wiki where each page is a Giper Baza land, edited live in the browser.

## Tools

- **MAM** — the build tool and module registry that every $mol app lives in — and it is itself a $mol project. [Source](https://github.com/hyoo-ru/mam).
- **view.tree LSP** — language tooling and the `npm create view-tree-lsp` scaffolder that starts new $mol apps.
- **This site** — the documentation you are reading, including the [Playground](#!section=playground) and [course](#!section=course), is a $mol app. The search, live code editor, and in-browser TypeScript are all built with the framework they document.

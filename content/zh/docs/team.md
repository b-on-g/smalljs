# 团队

$mol 由 **[hyoo-ru](https://github.com/hyoo-ru)** 公开构建——这是围绕其作者 Dmitry Karlovsky（[nin-jin](https://github.com/nin-jin)）的社区。开发发生在单一 monorepo [mam_mol](https://github.com/hyoo-ru/mam_mol) 中，框架、它的组件和工具全都共同生活在那里。

这个生态是集体的努力：核心框架、CRDT 库 [$hyoo_crowd](https://github.com/hyoo-ru/crowd.hyoo.ru)、[Giper Baza](https://github.com/giper-dev/baza)，以及数十个已发布的组件，全都来自在同一个工作区工作的贡献者。

## 参与贡献

- 整个生态都采用 MIT 许可证，欢迎 pull request。
- 每个模块都住在 [mam_mol](https://github.com/hyoo-ru/mam_mol) monorepo 里——fork、加一个文件夹、开一个 PR。
- 在 [DEV 社区](https://dev.to/t/mol)讨论想法，分享你的作品。

本文档站点单独维护于 [b-on-g/smalljs](https://github.com/b-on-g/smalljs)；如果你发现有可改进之处，每个页面都有一个 *在 GitHub 上编辑* 链接。

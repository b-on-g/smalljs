# $mol_list

继承自 `$mol_view`。[在 GitHub 上查看源码](https://github.com/hyoo-ru/mam_mol/tree/master/list)

本参考由组件的带类型 `.view.tree` 接口生成。

## 属性

| 属性 | 访问 | 类型 |
|---|---|---|
| `gap_before` | 读 | `number` |
| `Gap_before` | 读 | `$mol_view` |
| `Empty` | 读 | `$mol_view` |
| `gap_after` | 读 | `number` |
| `Gap_after` | 读 | `$mol_view` |
| `rows` | 读 | `readonly($mol_view)[]` |
| `render_visible_only` | 读 | `boolean` |
| `render_over` | 读 | `number` |
| `sub` | 读 | `as 'rows'` |
| `view_window_shift` | 读 / 写 | `number` |
| `view_window` | 读 | `readonly(any)[]` |

# $mol_number

继承自 `$mol_view`。[在 GitHub 上查看源码](https://github.com/hyoo-ru/mam_mol/tree/master/number)

本参考由组件的带类型 `.view.tree` 接口生成。

| `inc_icon` | 读 | `$mol_icon_chevron_right` |
| `Inc` | 读 | `$mol_button_minor` |
| `precision_view` | 读 | `as 'precision'` |
| `precision_change` | 读 | `as 'precision'` |

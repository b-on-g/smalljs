# 幽灵视图

`$mol_ghost` 是一个**无节点**的视图。它不创建自己的 DOM 元素，而是借用它的 `Sub()` 的元素，并把自己的属性、样式和行为混入其中。用源码里的一句话说：*“把视图逻辑混入另一个组件的 DOM 节点。”*

```tree
$mol_ghost $mol_view
	Sub $mol_view
```

普通的 `$mol_view` 会渲染自己的元素。幽灵**一个也不**渲染——它复用子组件的元素，因此不会向 DOM 树添加任何多余的东西。

## 何时用它

当你想给一个已有组件附加行为、又*不想*用另一个元素把它包起来时，就用幽灵——拖动、放置、随滚动跟随、过渡。框架中好几个组件都建立在它之上：

- **`$mol_drag`** / **`$mol_drop`**——指针拖放
- **`$mol_transit`**——进入/离开过渡
- **`$mol_follower`**——让一个元素随另一个滚动时保持对齐
- **`$mol_book_page`**——`$mol_book2` 导航中的一页

## 与插件的关系

`$mol_plugin`——每个[插件](#!section=docs/page=plugins)所扩展的基类——出于同样的原因也是无元素的：它增强宿主的元素，而不是新增一个。幽灵是通用形式（包住一个子组件并接管它的节点）；插件是你在 `plugins /` 下列出的那种专门化形式。

# $mol_paragraph

继承自 `$mol_view`。[在 GitHub 上查看源码](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

本参考由组件的带类型 `.view.tree` 接口生成。

## 属性

| 属性 | 访问 | 类型 |
|---|---|---|
| `line_height` | 读 | `number` |
| `letter_width` | 读 | `number` |
| `width_limit` | 读 | `number` |
| `row_width` | 读 | `number` |
| `sub` | 读 | `readonly(any)[]` |

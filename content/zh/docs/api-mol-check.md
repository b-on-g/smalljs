# $mol_check

继承自 `$mol_button_minor`。[在 GitHub 上查看源码](https://github.com/hyoo-ru/mam_mol/tree/master/check)

本参考由组件的带类型 `.view.tree` 接口生成。

## 属性

| 属性 | 访问 | 类型 |
|---|---|---|
| `checked` | 读 / 写 | `boolean` |
| `aria_checked` | 读 | `string` |
| `aria_role` | 读 | `string` |
| `title` | 读 | `string` |
| `Title` | 读 | `$mol_view` |
| `label` | 读 | `readonly(any)[]` |
| `attr` | 读 | `({` |
| `sub` | 读 | `readonly($mol_view_content)[]` |

# Équipe

$mol est construit au grand jour par **[hyoo-ru](https://github.com/hyoo-ru)** — la communauté autour de son auteur, Dmitry Karlovsky ([nin-jin](https://github.com/nin-jin)). Le développement se fait dans un unique monorepo, [mam_mol](https://github.com/hyoo-ru/mam_mol), où le framework, ses composants et l'outillage vivent tous ensemble.

L'écosystème est un effort collectif : le framework de base, la bibliothèque CRDT [$hyoo_crowd](https://github.com/hyoo-ru/crowd.hyoo.ru), [Giper Baza](https://github.com/giper-dev/baza) et des dizaines de composants publiés proviennent tous de contributeurs travaillant dans le même espace de travail.

## Contribuer

- Tout l'écosystème est sous licence MIT et ouvert aux pull requests.
- Chaque module vit dans le monorepo [mam_mol](https://github.com/hyoo-ru/mam_mol) — forkez, ajoutez un dossier, ouvrez une PR.
- Échangez des idées et partagez ce que vous construisez dans la [communauté DEV](https://dev.to/t/mol).

Ce site de documentation est maintenu séparément sur [b-on-g/smalljs](https://github.com/b-on-g/smalljs) ; chaque page a un lien *Éditer sur GitHub* si vous repérez quelque chose à améliorer.

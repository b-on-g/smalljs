# $mol_pick

`$mol_pop`을(를) 확장합니다. [GitHub에서 소스 보기](https://github.com/hyoo-ru/mam_mol/tree/master/pick)

이 레퍼런스는 컴포넌트의 타입이 있는 `.view.tree` 인터페이스에서 생성됩니다.

## 속성

| 속성 | 접근 | 타입 |
|---|---|---|
| `trigger_enabled` | 읽기 | `boolean` |
| `trigger_content` | 읽기 | `readonly($mol_view_content)[]` |
| `hint` | 읽기 | `string` |
| `Trigger` | 읽기 | `$mol_check` |
| `event` | 읽기 | `({` |
| `Anchor` | 읽기 | `as 'Trigger'` |

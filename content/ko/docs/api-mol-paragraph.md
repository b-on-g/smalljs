# $mol_paragraph

`$mol_view`을(를) 확장합니다. [GitHub에서 소스 보기](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

이 레퍼런스는 컴포넌트의 타입이 있는 `.view.tree` 인터페이스에서 생성됩니다.

## 속성

| 속성 | 접근 | 타입 |
|---|---|---|
| `line_height` | 읽기 | `number` |
| `letter_width` | 읽기 | `number` |
| `width_limit` | 읽기 | `number` |
| `row_width` | 읽기 | `number` |
| `sub` | 읽기 | `readonly(any)[]` |

# $mol_number

`$mol_view`을(를) 확장합니다. [GitHub에서 소스 보기](https://github.com/hyoo-ru/mam_mol/tree/master/number)

이 레퍼런스는 컴포넌트의 타입이 있는 `.view.tree` 인터페이스에서 생성됩니다.

## 속성

| 속성 | 접근 | 타입 |
|---|---|---|
| `precision` | 읽기 | `number` |
| `Hotkey` | 읽기 | `$mol_hotkey` |
| `dec_enabled` | 읽기 | `as 'enabled'` |
| `dec_icon` | 읽기 | `$mol_icon_chevron_left` |
| `Dec` | 읽기 | `$mol_button_minor` |
| `type` | 읽기 | `string` |
| `value_string` | 읽기 / 쓰기 | `string` |
| `hint` | 읽기 | `string` |
| `string_enabled` | 읽기 | `as 'enabled'` |
| `String` | 읽기 | `$mol_string` |
| `inc_enabled` | 읽기 | `as 'enabled'` |
| `inc_icon` | 읽기 | `$mol_icon_chevron_right` |
| `Inc` | 읽기 | `$mol_button_minor` |
| `precision_view` | 읽기 | `as 'precision'` |
| `precision_change` | 읽기 | `as 'precision'` |
| `boost` | 읽기 | `number` |
| `value_min` | 읽기 | `number` |
| `value_max` | 읽기 | `number` |
| `value` | 읽기 / 쓰기 | `number` |
| `enabled` | 읽기 | `boolean` |
| `plugins` | 읽기 | `readonly(any)[]` |
| `sub` | 읽기 | `readonly(any)[]` |

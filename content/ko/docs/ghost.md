# 고스트 뷰

`$mol_ghost`는 **노드가 없는** 뷰입니다. 자기 DOM 요소를 만드는 대신, 그 `Sub()`의 요소를 빌려 거기에 자기 자신의 속성, 스타일, 동작을 섞어 넣습니다. 소스의 한 줄로 말하면, *"뷰 로직을 다른 컴포넌트의 DOM 노드에 믹스인한다."*

```tree
$mol_ghost $mol_view
	Sub $mol_view
```

보통의 `$mol_view`는 자기 요소를 렌더링합니다. 고스트는 **하나도** 렌더링하지 않습니다——자식의 요소를 재사용하므로, DOM 트리에 여분의 것이 전혀 추가되지 않습니다.

## 언제 손을 뻗나

기존 컴포넌트에 또 다른 요소로 감싸지 *않고* 동작을 붙이고 싶을 때 고스트를 쓰세요——드래그, 드롭, 스크롤 따라가기, 전환. 프레임워크의 여러 컴포넌트가 이 위에 세워져 있습니다:

- **`$mol_drag`** / **`$mol_drop`**——포인터 드래그 앤 드롭
- **`$mol_transit`**——진입/이탈 전환
- **`$mol_follower`**——스크롤될 때 한 요소를 다른 요소에 정렬한 채 유지
- **`$mol_book_page`**——`$mol_book2` 내비게이션 안의 한 페이지

## 플러그인과의 관계

`$mol_plugin`——모든 [플러그인](#!section=docs/page=plugins)이 확장하는 기반——도 같은 이유로 요소가 없습니다: 호스트의 요소를 추가하는 대신 증강하기 때문입니다. 고스트는 일반형(자식 하나를 감싸 그 노드를 넘겨받음)이고, 플러그인은 `plugins /` 아래에 나열하는 특수화된 형태입니다.

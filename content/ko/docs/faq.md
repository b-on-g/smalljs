# 자주 묻는 질문

## smalljs란?

smalljs는 **$mol**의 문서 사이트입니다——타입이 있는 뷰, 자동 반응성, 가상 DOM이 없는 반응형 UI 프레임워크입니다. 프레임워크 자체는 hyoo-ru 커뮤니티가 공개적으로 개발합니다; 이 사이트는 가이드, 인터랙티브 코스, 라이브 플레이그라운드, API 레퍼런스를 한곳에 모읍니다.

## $mol은 프로덕션에 쓸 수 있나요?

네. $mol은 실제 앱과 내부 도구를 구동합니다——[쇼케이스](#!section=docs/page=showcase)를 보세요. 단일 모노레포(MAM)에서 배포되며, 저자와 커뮤니티가 매일 사용합니다.

## 런타임은 얼마나 큰가요?

작습니다. 전형적인 $mol 앱은 약 100 KB의 프레임워크 코드를 배포하고, 렌더링은 기본으로 가상화됩니다——뷰포트 밖의 컴포넌트는 결코 생성되지 않습니다. 자세한 내용과 벤치마크는 [렌더링](#!section=docs/page=rendering)을 보세요.

## 새 템플릿 언어를 배워야 하나요?

컴포넌트 레이아웃을 선언하는 간결한 트리 문법인 `view.tree`를 배웁니다. 의도적으로 작습니다——[뷰](#!section=docs/page=views) 장이 필요한 모든 것을 한 번에 다룹니다. 로직은 평범한 TypeScript 그대로이고, 스타일도 타입이 있습니다.

## React, Vue, Svelte와 어떻게 다른가요?

반응성은 자동입니다——`useState`도, `useEffect`도, 수동 구독도 없습니다. 여러분은 UI가 *무엇인지*를 기술하고, $mol이 *어떻게*, *언제* 갱신할지 결정합니다. [개념 대조표](#!section=docs/page=rosetta)가 다른 프레임워크의 개념을 $mol에 매핑합니다.

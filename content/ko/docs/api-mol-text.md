# $mol_text

`$mol_list`을(를) 확장합니다. [GitHub에서 소스 보기](https://github.com/hyoo-ru/mam_mol/tree/master/text/text)

이 레퍼런스는 컴포넌트의 타입이 있는 `.view.tree` 인터페이스에서 생성됩니다.

## 속성

| 속성 | 접근 | 타입 |
|---|---|---|
| `highlight` | 읽기 | `string` |
| `code_sidebar_showed` | 읽기 | `boolean` |
| `pre_sidebar_showed` | 읽기 | `as 'code_sidebar_showed'` |
| `uri_base` | 읽기 | `string` |
| `text` | 읽기 | `string` |
| `param` | 읽기 | `string` |
| `flow_tokens` | 읽기 | `readonly(any)[]` |
| `auto` | 읽기 | `readonly(any)[]` |

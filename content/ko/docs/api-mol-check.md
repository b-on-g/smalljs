# $mol_check

`$mol_button_minor`을(를) 확장합니다. [GitHub에서 소스 보기](https://github.com/hyoo-ru/mam_mol/tree/master/check)

이 레퍼런스는 컴포넌트의 타입이 있는 `.view.tree` 인터페이스에서 생성됩니다.

## 속성

| 속성 | 접근 | 타입 |
|---|---|---|
| `checked` | 읽기 / 쓰기 | `boolean` |
| `aria_checked` | 읽기 | `string` |
| `aria_role` | 읽기 | `string` |
| `title` | 읽기 | `string` |
| `Title` | 읽기 | `$mol_view` |
| `label` | 읽기 | `readonly(any)[]` |
| `attr` | 읽기 | `({` |
| `sub` | 읽기 | `readonly($mol_view_content)[]` |

# Плагіни

**Плагін** — це компонент без власного DOM-елемента. Замість малюватися на сторінці, він прикріплює поведінку до елемента компонента, що його хостить, — дуже схоже на директиву. Плагіни ви перелічуєте під `plugins /` у view.tree; вони працюють поряд із поданням, але ніколи не з'являються в його `sub`.

```tree
$my_app $mol_view
	plugins /
		<= Theme $mol_theme_auto
		<= Search_key $mol_hotkey
			key *
				K? <=> open_search?
	sub /
		<= Content $my_content
```

Оскільки плагін ділить елемент свого хоста, він може додавати до цього елемента слухачів подій, атрибути чи реактивні побічні ефекти, не загортаючи його в додаткову розмітку.

## Плагіни, якими ви користуватиметеся часто

- **`$mol_hotkey`** — прив'язує клавіатурні скорочення. `key * escape? <=> close?` виконує `close` на Escape; встановіть `mod_ctrl true`, щоб вимагати Ctrl/⌘.
- **`$mol_theme_auto`** — застосовує світлу/темну тему до піддерева хоста.
- **`$mol_nav`** — навігація стрілками по списку компонентів (`keys_y`, `current_y`).
- **`$mol_speech`** — введення через розпізнавання мовлення.

## Як написати свій

Плагін розширює `$mol_plugin` (який сам без елемента) і зазвичай зв'язує `event` з обробником:

```tree
$my_autosave $mol_plugin
	event *
		^
		input? <=> save? null
```

Прикріпіть його до будь-якого подання через список `plugins /` цього подання, і він розширить елемент цього подання.

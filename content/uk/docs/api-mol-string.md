# $mol_string

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/string)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `disabled` | читання | `boolean` |
| `value` | читання / запис | `string` |
| `value_changed` | читання / запис | `as 'value'` |
| `hint` | читання | `string` |
| `hint_visible` | читання | `as 'hint'` |
| `spellcheck` | читання | `boolean` |
| `autocomplete_native` | читання | `string` |
| `selection_end` | читання | `number` |
| `selection_start` | читання | `number` |
| `keyboard` | читання | `string` |
| `enter` | читання | `string` |
| `length_max` | читання | `number` |
| `type` | читання / запис | `string` |
| `submit_with_ctrl` | читання | `boolean` |
| `Submit` | читання | `$mol_hotkey` |
| `dom_name` | читання | `string` |
| `enabled` | читання | `boolean` |
| `minimal_height` | читання | `number` |

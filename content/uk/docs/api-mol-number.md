# $mol_number

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/number)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `precision` | читання | `number` |
| `Hotkey` | читання | `$mol_hotkey` |
| `dec_enabled` | читання | `as 'enabled'` |
| `dec_icon` | читання | `$mol_icon_chevron_left` |
| `Dec` | читання | `$mol_button_minor` |
| `type` | читання | `string` |
| `value_string` | читання / запис | `string` |
| `hint` | читання | `string` |
| `string_enabled` | читання | `as 'enabled'` |
| `String` | читання | `$mol_string` |
| `inc_enabled` | читання | `as 'enabled'` |
| `inc_icon` | читання | `$mol_icon_chevron_right` |
| `Inc` | читання | `$mol_button_minor` |
| `precision_view` | читання | `as 'precision'` |
| `precision_change` | читання | `as 'precision'` |
| `boost` | читання | `number` |
| `value_min` | читання | `number` |
| `value_max` | читання | `number` |
| `value` | читання / запис | `number` |
| `enabled` | читання | `boolean` |
| `plugins` | читання | `readonly(any)[]` |
| `sub` | читання | `readonly(any)[]` |

# $mol_pick

Розширює `$mol_pop`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/pick)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `trigger_enabled` | читання | `boolean` |
| `trigger_content` | читання | `readonly($mol_view_content)[]` |
| `hint` | читання | `string` |
| `Trigger` | читання | `$mol_check` |
| `event` | читання | `({` |
| `Anchor` | читання | `as 'Trigger'` |

# $mol_scroll

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/scroll)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `tabindex` | читання | `number` |
| `scroll_top` | читання / запис | `number` |
| `scroll_left` | читання / запис | `number` |
| `attr` | читання | `({` |
| `event` | читання | `({` |

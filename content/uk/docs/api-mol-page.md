# $mol_page

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/page)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `tabindex` | читання | `number` |
| `title_content` | читання | `readonly(any)[]` |
| `Title` | читання | `$mol_view` |
| `tools` | читання | `readonly($mol_view_content)[]` |
| `Tools` | читання | `$mol_view` |
| `head` | читання | `readonly(any)[]` |
| `Head` | читання | `$mol_view` |
| `body_scroll_top` | читання / запис | `ReturnType< as 'Body'['scroll_top'] >` |
| `body` | читання | `readonly($mol_view)[]` |
| `Body_content` | читання | `$mol_view` |
| `body_content` | читання | `readonly(any)[]` |
| `Body` | читання | `$mol_scroll` |
| `foot` | читання | `readonly($mol_view)[]` |
| `Foot` | читання | `$mol_view` |
| `dom_name` | читання | `string` |
| `attr` | читання | `({` |
| `sub` | читання | `readonly(any)[]` |

# $mol_check

Розширює `$mol_button_minor`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/check)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `checked` | читання / запис | `boolean` |
| `aria_checked` | читання | `string` |
| `aria_role` | читання | `string` |
| `title` | читання | `string` |
| `Title` | читання | `$mol_view` |
| `label` | читання | `readonly(any)[]` |
| `attr` | читання | `({` |
| `sub` | читання | `readonly($mol_view_content)[]` |

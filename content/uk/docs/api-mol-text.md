# $mol_text

Розширює `$mol_list`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/text/text)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `highlight` | читання | `string` |
| `code_sidebar_showed` | читання | `boolean` |
| `pre_sidebar_showed` | читання | `as 'code_sidebar_showed'` |
| `uri_base` | читання | `string` |
| `text` | читання | `string` |
| `param` | читання | `string` |
| `flow_tokens` | читання | `readonly(any)[]` |
| `auto` | читання | `readonly(any)[]` |

# $mol_paragraph

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `line_height` | читання | `number` |
| `letter_width` | читання | `number` |
| `width_limit` | читання | `number` |
| `row_width` | читання | `number` |
| `sub` | читання | `readonly(any)[]` |

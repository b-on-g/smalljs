# $mol_list

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/list)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `gap_before` | читання | `number` |
| `Gap_before` | читання | `$mol_view` |
| `Empty` | читання | `$mol_view` |
| `gap_after` | читання | `number` |
| `Gap_after` | читання | `$mol_view` |
| `rows` | читання | `readonly($mol_view)[]` |
| `render_visible_only` | читання | `boolean` |
| `render_over` | читання | `number` |
| `sub` | читання | `as 'rows'` |
| `view_window_shift` | читання / запис | `number` |
| `view_window` | читання | `readonly(any)[]` |

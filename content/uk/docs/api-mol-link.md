# $mol_link

Розширює `$mol_view`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/link)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

| Властивість | Доступ | Тип |

| `target` | читання | `string` |
| `file_name` | читання | `string` |
| `current` | читання | `boolean` |
| `relation` | читання | `string` |
| `click` | читання / запис | `as 'event_click'` |

# $mol_button_minor

Розширює `$mol_button_typed`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/button/minor)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

$mol_button_minor adds no new bindable properties of its own — see `$mol_button_typed`.

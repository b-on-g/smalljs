# $mol_select

Розширює `$mol_pick`. [Переглянути код на GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/select)

Цей довідник згенеровано з типізованого інтерфейсу `.view.tree` компонента.

## Властивості

| Властивість | Доступ | Тип |
|---|---|---|
| `enabled` | читання | `boolean` |
| `filter_pattern` | читання / запис | `string` |
| `no_options_message` | читання | `string` |
| `nav_components` | читання | `readonly($mol_view)[]` |
| `nav_cycle` | читання / запис | `boolean` |
| `Nav` | читання | `$mol_nav` |
| `menu_content` | читання | `readonly($mol_view)[]` |
| `Menu` | читання | `$mol_list` |
| `Bubble_pane` | читання | `$mol_scroll` |
| `filter_hint` | читання | `string` |
| `dictionary` | читання / запис | `Record<string, any>` |
| `options` | читання | `readonly(string)[]` |
| `value` | читання / запис | `string` |
| `option_label_default` | читання | `string` |
| `No_options` | читання | `$mol_view` |
| `plugins` | читання | `readonly(any)[]` |
| `hint` | читання | `string` |
| `bubble_content` | читання | `readonly(any)[]` |
| `Filter` | читання | `$mol_search` |
| `Trigger_icon` | читання | `$mol_icon_dots_vertical` |
| `trigger_enabled` | читання | `as 'enabled'` |

# $mol_list

繼承自 `$mol_view`。[在 GitHub 上查看原始碼](https://github.com/hyoo-ru/mam_mol/tree/master/list)

| `gap_before` | 讀 | `number` |

| `Empty` | 讀 | `$mol_view` |
| `gap_after` | 讀 | `number` |
| `Gap_after` | 讀 | `$mol_view` |
| `rows` | 讀 | `readonly($mol_view)[]` |

| `render_over` | 讀 | `number` |
| `sub` | 讀 | `as 'rows'` |
| `view_window_shift` | 讀 / 寫 | `number` |
| `view_window` | 讀 | `readonly(any)[]` |

# $mol_paragraph

繼承自 `$mol_view`。[在 GitHub 上查看原始碼](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

本參考由元件的帶型別 `.view.tree` 介面生成。

## 屬性

| 屬性 | 存取 | 型別 |
|---|---|---|
| `line_height` | 讀 | `number` |
| `letter_width` | 讀 | `number` |
| `width_limit` | 讀 | `number` |
| `row_width` | 讀 | `number` |
| `sub` | 讀 | `readonly(any)[]` |

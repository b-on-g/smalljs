# 團隊

$mol 由 **[hyoo-ru](https://github.com/hyoo-ru)** 公開建構——這是圍繞其作者 Dmitry Karlovsky（[nin-jin](https://github.com/nin-jin)）的社群。開發發生在單一 monorepo [mam_mol](https://github.com/hyoo-ru/mam_mol) 中，框架、它的元件和工具全都共同生活在那裏。

這個生態是集體的努力：核心框架、CRDT 函式庫 [$hyoo_crowd](https://github.com/hyoo-ru/crowd.hyoo.ru)、[Giper Baza](https://github.com/giper-dev/baza)，以及數十個已發布的元件，全都來自在同一個工作區工作的貢獻者。

## 參與貢獻

- 整個生態都採用 MIT 授權，歡迎 pull request。
- 每個模組都住在 [mam_mol](https://github.com/hyoo-ru/mam_mol) monorepo 裏——fork、加一個資料夾、開一個 PR。
- 在 [DEV 社群](https://dev.to/t/mol)討論想法，分享你的作品。

本文件網站單獨維護於 [b-on-g/smalljs](https://github.com/b-on-g/smalljs)；如果你發現有可改進之處，每個頁面都有一個 *在 GitHub 上編輯* 連結。

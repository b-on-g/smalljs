# 幽靈視圖

`$mol_ghost` 是一個**無節點**的視圖。它不建立自己的 DOM 元素，而是借用它的 `Sub()` 的元素，並把自己的屬性、樣式和行為混入其中。用原始碼裏的一句話說：*「把視圖邏輯混入另一個元件的 DOM 節點。」*

```tree
$mol_ghost $mol_view
	Sub $mol_view
```

普通的 `$mol_view` 會渲染自己的元素。幽靈**一個也不**渲染——它複用子元件的元素，因此不會向 DOM 樹添加任何多餘的東西。

## 何時用它

當你想給一個已有元件附加行為、又*不想*用另一個元素把它包起來時，就用幽靈——拖動、放置、隨捲動跟隨、過渡。框架中好幾個元件都建立在它之上：

- **`$mol_drag`** / **`$mol_drop`**——指標拖放
- **`$mol_transit`**——進入/離開過渡
- **`$mol_follower`**——讓一個元素隨另一個捲動時保持對齊
- **`$mol_book_page`**——`$mol_book2` 導覽中的一頁

## 與外掛的關係

`$mol_plugin`——每個[外掛](#!section=docs/page=plugins)所擴充的基底類別——出於同樣的原因也是無元素的：它增強宿主的元素，而不是新增一個。幽靈是通用形式（包住一個子元件並接管它的節點）；外掛是你在 `plugins /` 下列出的那種專門化形式。

# $mol_paragraph

`$mol_view` را گسترش می‌دهد. [دیدنِ سورس در GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/paragraph)

این مرجع از واسطِ نوع‌دارِ `.view.tree`ِ کامپوننت تولید شده است.

## ویژگی‌ها

| ویژگی | دسترسی | نوع |
|---|---|---|
| `line_height` | خواندن | `number` |
| `letter_width` | خواندن | `number` |
| `width_limit` | خواندن | `number` |
| `row_width` | خواندن | `number` |
| `sub` | خواندن | `readonly(any)[]` |

# $mol_number

`$mol_view` را گسترش می‌دهد. [دیدنِ سورس در GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/number)

این مرجع از واسطِ نوع‌دارِ `.view.tree`ِ کامپوننت تولید شده است.

## ویژگی‌ها

| ویژگی | دسترسی | نوع |
|---|---|---|
| `precision` | خواندن | `number` |
| `Hotkey` | خواندن | `$mol_hotkey` |
| `dec_enabled` | خواندن | `as 'enabled'` |
| `dec_icon` | خواندن | `$mol_icon_chevron_left` |
| `Dec` | خواندن | `$mol_button_minor` |
| `type` | خواندن | `string` |
| `value_string` | خواندن / نوشتن | `string` |
| `hint` | خواندن | `string` |
| `string_enabled` | خواندن | `as 'enabled'` |
| `String` | خواندن | `$mol_string` |
| `inc_enabled` | خواندن | `as 'enabled'` |
| `inc_icon` | خواندن | `$mol_icon_chevron_right` |
| `Inc` | خواندن | `$mol_button_minor` |
| `precision_view` | خواندن | `as 'precision'` |
| `precision_change` | خواندن | `as 'precision'` |
| `boost` | خواندن | `number` |
| `value_min` | خواندن | `number` |
| `value_max` | خواندن | `number` |
| `value` | خواندن / نوشتن | `number` |
| `enabled` | خواندن | `boolean` |
| `plugins` | خواندن | `readonly(any)[]` |
| `sub` | خواندن | `readonly(any)[]` |

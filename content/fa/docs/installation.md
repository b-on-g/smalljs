# نصب

[شروع به کار](#!section=docs/page=getting-started) گام‌به‌گام شما را در ساخت نخستین برنامه‌تان راهنمایی می‌کند. این صفحه مرجع است: اینکه یک پروژهٔ $mol چگونه سازمان‌دهی می‌شود و ساخت (build) چگونه کار می‌کند.

## پیش‌نیازها

- **Node.js 18+** و **git**. چیز دیگری به‌صورت سراسری نصب نمی‌شود.

## فضای کاری MAM

برنامه‌های $mol درون **MAM** زندگی می‌کنند — ابزار ساخت و رجیستری ماژول‌ها. یک بار آن را کلون می‌کنید و ماژول‌های خود را درون آن توسعه می‌دهید:

```bash
git clone https://github.com/hyoo-ru/mam.git ./mam
cd mam
npm install
npm start
```

`npm start` یک سرور توسعهٔ نظارتی روی `http://localhost:9080/` اجرا می‌کند. هنگام ذخیره دوباره می‌سازد و وابستگی‌ها را به‌صورت خودکار حل می‌کند — هرگز پیکربندی باندلر را نگهداری نمی‌کنید.

## چگونگی نام‌گذاری ماژول‌ها

هر نام مؤلفه به یک مسیر پوشه نگاشته می‌شود و **هر زیرخط (underscore) یک جداکنندهٔ پوشه است**:

```
$my_app          →  my/app/
$my_app_header   →  my/app/header/
```

نام پوشهٔ ماژول‌ها هرگز شامل زیرخط نیست — برای نام‌های چندکلمه‌ای از پوشه‌های تودرتو استفاده کنید. اگر مؤلفه‌ای که استفاده می‌کنید هرگز در باندل ظاهر نشد، تقریباً همیشه مسیر پوشه با نام کلاس مطابقت ندارد.

## کالبدشکافی یک ماژول

هر مؤلفه یک پوشه است که تا چهار فایل دارد:

| فایل | کاربرد |
|------|------|
| `name.view.tree` | چیدمان اعلانی |
| `name.view.ts` | رفتار (TypeScript) |
| `name.view.css.ts` | سبک‌های نوع‌دار |
| `name.view.tree`، `index.html` | نقطهٔ ورود یک ماژول برنامه |

فایل `index.html` یک برنامه مؤلفهٔ ریشه را نصب (mount) می‌کند:

```html
<body mol_view_root>
	<div mol_view_root="$my_app"></div>
	<script src="web.js"></script>
</body>
```

## ساخت برای تولید (production)

سرور توسعه در لحظه می‌سازد، اما می‌توانید هر ماژولی را به‌صراحت از ریشهٔ فضای کاری بسازید:

```bash
npm run start my/app
```

خروجی در `my/app/-/` قرار می‌گیرد — شامل `web.js`، `web.css` و `web.audit.js`. **همیشه فایل حسابرسی (audit) را بررسی کنید:** یک `web.audit.js` تمیز یعنی هیچ وابستگی بلااستفاده و هیچ خطای نوعی وجود ندارد.

## افزودن بسته‌های npm

با `require` به یک بسته ارجاع دهید و MAM آن را در ساخت بعدی نصب می‌کند:

```typescript
const dayjs = require( 'dayjs' ) as typeof import( 'dayjs' )
```

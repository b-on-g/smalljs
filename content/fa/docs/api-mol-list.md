# $mol_list

`$mol_view` را گسترش می‌دهد. [دیدنِ سورس در GitHub](https://github.com/hyoo-ru/mam_mol/tree/master/list)

این مرجع از واسطِ نوع‌دارِ `.view.tree`ِ کامپوننت تولید شده است.

## ویژگی‌ها

| ویژگی | دسترسی | نوع |
|---|---|---|
| `gap_before` | خواندن | `number` |
| `Gap_before` | خواندن | `$mol_view` |
| `Empty` | خواندن | `$mol_view` |
| `gap_after` | خواندن | `number` |
| `Gap_after` | خواندن | `$mol_view` |
| `rows` | خواندن | `readonly($mol_view)[]` |
| `render_visible_only` | خواندن | `boolean` |
| `render_over` | خواندن | `number` |
| `sub` | خواندن | `as 'rows'` |
| `view_window_shift` | خواندن / نوشتن | `number` |
| `view_window` | خواندن | `readonly(any)[]` |
